## 1. 整体架构（推荐）

```
微信群 / 熟人转发
        │
        ▼
  游戏独立页（鹈鹕换皮 · 同城拉力赛）
  路径示例：https://xinhe.site/game/rally/   ← 静态资源，Nginx 直出
        │
        ├─ 每日免费 N 次（localStorage + 可选手机号）
        ├─ 次数用尽 → 复制活动链接 / 系统分享 → 本地+1（弱校验）
        ├─ 排行榜（里程/抓鱼数，先前端+轻量后端）
        └─ 强 CTA：「加红娘微信领奖 / 报名上架」
                │
                ▼
        相亲站 /join 或 ContactSheet 加微
                │
                ▼
        红娘后台审线索 → 沉淀到交友池
```

**为什么游戏独立、不嵌进相亲站 SPA？**

1. 文档已定：站 A 不做分游，避免相亲路径变杂。  
2. WebGL 在 iframe / 微信 WebView 里坑多；**整页跳转**更稳。  
3. 游戏迭代不拖现网发版；坏了也不影响相亲主流程。

现网只做两件事：**Banner 外链 + 公告写规则**（改动最小）。

## 2. 分阶段怎么做（按 ROI）

### 阶段 A · 本周验证（1 天，必做）

**完成标准：**

1. 鹈鹕换皮：标题改成「新缘网 · 同城拉力赛」（或更土更本地的名字），去掉纯开源 demo 感。  
2. 每日免费次数（建议 3）+ 用尽弹层：「复制链接发给好友，回来点『我已分享』+1 次」。  
3. 固定 CTA 按钮：跳转相亲站报名页或弹出红娘微信号/二维码。  
4. 扔进 **已有微信群 / 熟人**，记四个数：打开、分享点击、加微、报名。

**成功 / 失败：**

| 结果 | 动作 |
| --- | --- |
| 有人玩 + 有人加微/报名 | 进入阶段 B |
| 几乎无人分享、零留资 | **封存游戏代码**，只复盘文案与群，不再加功能 |

**明确不做：** 服务器联机、微信 JS-SDK、飞车/运输船、改现网后端大模块。

### 阶段 B · 本地活动闭环（有数据再做）

1. 谈 2～3 家本地店（洗车 / 餐饮）要 **低价券** 做周榜奖品（可倒贴小几百）。  
2. 公告页写清：第 1～3 名怎么领、要不要到店核销。  
3. 游戏结算页强化：「留手机号 / 加微领券」。  
4. 现网首页 Banner 挂活动（`link_url` → 游戏 URL）。

### 阶段 C · 轻量后端（仍小改）

仅当阶段 B 有作弊或要认真发奖时再加：

- 极简 API：`device_id / phone` + 每日次数 + 成绩提交 + Top50  
- 可挂在 `相亲站/api` 旁路新路由，或 Nginx 下单独小服务  
- **不要**强绑现网 JWT / 电量体系（电量≠游戏分，绑了反而乱）

### 阶段 D · B 端打包（有案例再说）

把「换皮 + 次数 + 排行 + 留资 CTA」收成模板，卖县城商超/楼盘——前提是你手里有 **一次真实活动数据截图**。

## 3. 技术落点（对应仓库文件）

### A. 游戏仓 `h5-playables/pelican-bike/`

| 改动 | 说明 |
| --- | --- |
| 文案 / 品牌 | `index.template.html`：标题、按钮、页脚改「新缘网·同城拉力赛」 |
| 次数墙 | `src/main.js`（或新建 `src/quota.js`）：localStorage 记日期与剩余次数 |
| 分享墙（弱） | 弹层：`navigator.clipboard` / `navigator.share`；按钮「我已分享」本地 +1（可防刷弱一点，验证阶段够用） |
| CTA | 结算/次数用尽：`window.location` → 相亲站 `/join` 或 `https://xinhe.site/...` |
| 构建 | `npm i && node build.mjs` → `dist/index.html` 上传 |

### B. 站点仓 `xiangqin-site`（尽量少动）

| 改动 | 路径 | 说明 |
| --- | --- | --- |
| 静态托管游戏 | 服务器 `/www/wwwroot/xinhe.site/game/rally/` | 只丢 `dist`，不进相亲站 Vue 工程 |
| Banner | 后台 Banner `link_url` | 指向 `/game/rally/` |
| 公告 | Announcements | 规则 + 领奖说明 |
| CTA 目标 | `相亲站/web` 的 `/join` 或 ContactSheet | **线索终点** |
| 工具站 iframe | **不推荐优先** | 微信里 iframe 易挂；整页跳转优先 |

### C. 域名与合规

| 项 | 建议 |
| --- | --- |
| 活动域名 | 先用 `xinhe.site/game/rally/`（同域，无 CORS  hassle） |
| 备案前 | 仅群测；不做抖音投放、不做「关注公众号才能玩」 |
| 版权 | 只用鹈鹕；飞车/运输船不进活动物料 |

## 4. 产品文案骨架（可直接改）

- **活动名：** 新缘网 · 同城拉力赛（第 1 季）  
- **一句话：** 骑上车抓鱼比里程，周榜前三领本地券；想脱单的顺便加红娘微信。  
- **规则三行：**  
  1. 每天免费 3 次；分享给好友可再加次数  
  2. 按本周最高分上榜  
  3. 领奖 / 脱单咨询 → 加红娘微信  

CTA 主按钮文案优先测这两个（一次只测一个）：

1. 「加红娘微信 · 领奖&脱单」  
2. 「报名上架嘉宾墙」

## 6. 和现有优先级的关系（避免三线并行）

`xiangqin-site` 文档已定：情感减压 > 闲鱼 > 站拆分；未备案不做大规模获客。

因此本方案默认：

- 拉力赛 = **小流量验证插件**，不是新主线产品  
- 代码时间 **封顶 1 天（阶段 A）**；跑不通就停  
- 不与「把现网大重构」抢精力
